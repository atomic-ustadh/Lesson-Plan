How to Install WordPress Locally with XAMPP

This guide will walk you through installing WordPress on your local machine using XAMPP.

Step 1: Download WordPress

First, you need to download the latest version of WordPress from the official website.

Go to https://wordpress.org/download/ and click the button to download the .zip file.

Step 2: Create a Database

Next, you need to create a database for your WordPress installation. Open your XAMPP control panel and start the Apache and MySQL modules. The XAMPP control panel is usually at the bottom right side of your taskbar.

Then, open your browser and go to http://localhost/phpmyadmin/.

At the top of the page, click on the "Databases" tab, enter a name for your database (e.g., wp_test_site), and click "Create".

Step 3: Unzip WordPress into XAMPP's htdocs Folder

Navigate to the folder where you installed XAMPP and find the htdocs directory (usually c:/xampp/htdocs).

Create a new folder inside htdocs for your WordPress site (e.g., my-wordpress-site).

Extract the contents of the WordPress .zip file you downloaded into this new folder.

Step 4: Configure the details and Installation of Wordpress

go to your browser and type localhost:80/my-wordpress-site

Click on "Let's go!" button

Fill in the database details as follows:

  • Database Name: the name you chose in phpMyAdmin
  • Database Host: localhost
  • Username: root
  • Password: leave it blank
  • Table prefix: wp_

Click "Submit" and then "Run the installation".

Step 5: Run the WordPress Installation

Now you're ready to install WordPress.

On the next screen, you will be asked for your site title, admin username, password, and email. Fill in these details and click "Install WordPress".

you can choose to use the generated password or create your own. But always copy your password

Click "Install WordPress".

Once the installation is complete, you will see a success message. You can now log in to your new WordPress site at http://localhost/my-wordpress-site/wp-admin/.

Step 6: Login to your dashboard and Start Building your website

After a successful installation, you will see a confirmation message. Click the "Log In" button to access your WordPress admin dashboard.

use your username and password to login

enter your credentials and login

you will be redirected to the WordPress dashboard where you can start customizing your site, adding themes, plugins, and content.

Click on view your site to see what you are building

Congratulations!

You have successfully installed WordPress on your local machine. You can now start building your website.
